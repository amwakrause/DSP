Project Overview

Welcome to Le Transcriber! Our project tackles a classic computer vision and digital signal processing challenge: taking raw 2D grayscale images of handwritten mathematical equations and automatically compiling them into clean, valid $\LaTeX$ code.

By leveraging OpenCV for spatial image segmentation and a custom recursive Abstract Syntax Tree (AST) compiler, our system translates structural 2D handwriting layouts into structured 1D markup.

1. Data Description

Our input dataset consists of 2D grayscale image arrays (saved as .png files) capturing handwritten equations containing numbers, variables, operators, and fractions. Future pipeline expansions will ingest multi-page PDF documents.

  • Resolution & Format: High-contrast grayscale matrices optimized for thresholding.
  • Signal Characteristics: Variable stroke widths, lighting variations, and background paper noise requiring digital filtering.

3. Progress Report & Challenges

What we've done so far: We built the complete preprocessing pipeline (Otsu binarization, morphological closing) and developed the core AST compiler mapping spatial relationships into nested $\LaTeX$ strings.

Challenges & Solutions:

  • Multi-part characters: Symbols like '=' or 'i' break into separate contours. Solution: Implemented vertical coordinate clustering to merge disconnected sub-strokes.
  • Complex fractions: 2D vertical hierarchy handling. Solution: Expanding our AST recursive visitor pattern to properly isolate numerator and denominator sub-trees.

4. Three-Week Action Plan

  • Week 1: Refine fraction tree parsing and implement $y$-axis line clustering for multi-line equations.
  • Week 2: Integrate a lightweight classifier to map bounding box features to concrete math tokens.
  • Week 3: Add PDF ingestion support via pypdfium2 and conduct end-to-end evaluation on test worksheets.

5. Technical Lesson Learned

Otsu’s Thresholding & Morphological Operations: Working with handwritten data taught us that static brightness thresholds fail instantly under uneven phone-camera lighting. Using Otsu's method treats pixel intensity histograms as a bimodal signal distribution, dynamically finding the optimal threshold. Pairing this with morphological closing acts as a spatial low-pass filter, patching microscopic gaps in pen strokes without distorting character boundaries.
